# @rifrocket/fdt-docs

Developer documentation site for `@rifrocket/fdt-*` — built with [Docusaurus 3](https://docusaurus.io/). Deployed to [rifrocket.github.io/fabricjs-design-tool](https://rifrocket.github.io/fabricjs-design-tool/) via `.github/workflows/docs-ci.yml` on merge to `main`.

**Status:** not published (`private: true`) — this is a documentation site, not a library package.

## Working in this app

From the repo root:

```bash
pnpm docs:dev        # start the local dev server (http://localhost:3000)
pnpm docs:build      # production build → apps/docs/dist
pnpm docs:typecheck  # tsc, including config/component files
```

`docs:*` are intentionally **not** part of the root `apps:*` scripts (which scope to `apps/demo` only) — see `docs-ci.yml`'s header comment for why the two are kept as separate CI gates.

## Content

- `docs/` — the MDX/Markdown content tree; folder structure (with `_category_.json` per folder) drives the sidebar via `sidebars.ts`'s `autogenerated` config.
- `docs/getting-started/quick-start.md` embeds [`packages/react/src/quickstart.example.tsx`](../../packages/react/src/quickstart.example.tsx) verbatim at build time via `remark-code-import` (wired in `docusaurus.config.ts`), so it can never drift from the real, CI-typechecked example.
- `src/components/`, `src/css/`, `src/pages/` — site chrome (homepage, theme CSS).

This app depends on several `@rifrocket/fdt-*` packages as `workspace:*` — run `pnpm packages:build` from the repo root first if you're building `apps/docs` standalone (Turborepo does this automatically via `docs:build`'s `dependsOn: ["^build"]`).
