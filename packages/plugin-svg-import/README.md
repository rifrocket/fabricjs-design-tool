# @rifrocket/fdt-plugin-svg-import

SVG import registered via the core plugin system — a net-new (not ported from v1) plugin proving the extension points are real.

## Install

```bash
npm install @rifrocket/fdt-plugin-svg-import
```

Peer dependencies: `fabric`.
Depends on `@rifrocket/fdt-core`.

Full usage: [/docs/plugins/svg-import](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/svg-import)
