# @rifrocket/fdt-plugin-import-json

JSON import (engine plugin + a bare React trigger button) for the FabricJS Design Tool v2.

## Install

```bash
npm install @rifrocket/fdt-plugin-import-json
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-react`.

Full usage: [/docs/plugins/import-json](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/import-json)
