# @rifrocket/fdt-plugin-shapes-basic

Default shape object types (text, rect, circle, line, ellipse, polygons) for the FabricJS Design Tool v2, registered via the core plugin system.

## Install

```bash
npm install @rifrocket/fdt-plugin-shapes-basic
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-properties`.

Full usage: [/docs/plugins/shapes-basic](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/shapes-basic)
