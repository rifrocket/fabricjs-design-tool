# @rifrocket/fdt-plugin-effects

Object effects system (shadow, glow, blur, glitch, duotone, ...) for the FabricJS Design Tool v2, registered via the core plugin system.

## Install

```bash
npm install @rifrocket/fdt-plugin-effects
```

Peer dependencies: `fabric`.
Depends on `@rifrocket/fdt-core`.

Full usage: [/docs/plugins/effects](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/effects)
