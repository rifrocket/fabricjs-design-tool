# @rifrocket/fdt-plugin-clipboard

Copy/paste/duplicate/group/select-all/nudge keyboard shortcuts for the FabricJS Design Tool v2, registered via the core plugin system.

## Install

```bash
npm install @rifrocket/fdt-plugin-clipboard
```

Peer dependencies: `fabric`.
Depends on `@rifrocket/fdt-core`.

Full usage: [/docs/plugins/clipboard](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/clipboard)
