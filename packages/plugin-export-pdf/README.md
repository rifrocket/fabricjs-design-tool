# @rifrocket/fdt-plugin-export-pdf

PDF export for the FabricJS Design Tool v2, extracted from core so jsPDF (and its transitive dependencies) is only paid for by consumers who install this plugin.

## Install

```bash
npm install @rifrocket/fdt-plugin-export-pdf
```

Peer dependencies: `fabric`.
Depends on `@rifrocket/fdt-core`, plus `jspdf`.

Full usage: [/docs/plugins/export-pdf](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/export-pdf)
