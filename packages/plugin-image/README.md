# @rifrocket/fdt-plugin-image

Image object type for the FabricJS Design Tool v2, registered via the core plugin system.

## Install

```bash
npm install @rifrocket/fdt-plugin-image
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-properties`.

Full usage: [/docs/plugins/image](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/image)
