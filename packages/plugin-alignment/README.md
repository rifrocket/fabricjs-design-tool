# @rifrocket/fdt-plugin-alignment

Bare align/distribute controls for the FabricJS Design Tool v2, wired to `AlignmentManager` (already in `@rifrocket/fdt-core` with no UI anywhere).

## Install

```bash
npm install @rifrocket/fdt-plugin-alignment
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-react`.

Full usage: [/docs/plugins/alignment](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/alignment)
