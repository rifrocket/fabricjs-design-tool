# @rifrocket/fdt-plugin-pan-zoom

Wheel-zoom and spacebar-drag-pan for a fixed-size canvas viewport, for the FabricJS Design Tool v2.

## Install

```bash
npm install @rifrocket/fdt-plugin-pan-zoom
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core`.

Full usage: [/docs/plugins/pan-zoom](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/pan-zoom)
