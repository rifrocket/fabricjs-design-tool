# @rifrocket/fdt-plugin-snapping

A bare on/off toggle for smart-guide snapping, for the FabricJS Design Tool v2.

## Install

```bash
npm install @rifrocket/fdt-plugin-snapping
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-react`.

Full usage: [/docs/plugins/snapping](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/snapping)
