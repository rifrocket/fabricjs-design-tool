# @rifrocket/fdt-plugin-qrcode

QR code object type (content generation, validation, styling) for the FabricJS Design Tool v2, registered via the core plugin system.

## Install

```bash
npm install @rifrocket/fdt-plugin-qrcode
```

Peer dependencies: `fabric`, `react`, `react-dom`.
Depends on `@rifrocket/fdt-core` and `@rifrocket/fdt-properties`, plus `qr-code-styling`.

Full usage: [/docs/plugins/qrcode](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/qrcode)
