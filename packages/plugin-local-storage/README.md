# @rifrocket/fdt-plugin-local-storage

Debounced localStorage autosave (engine plugin) plus save/load/clear primitives for the FabricJS Design Tool v2, built on `@rifrocket/fdt-core`'s document snapshot.

## Install

```bash
npm install @rifrocket/fdt-plugin-local-storage
```

Peer dependencies: `fabric`.
Depends on `@rifrocket/fdt-core`.

Full usage: [/docs/plugins/local-storage](https://rifrocket.github.io/fabricjs-design-tool/docs/plugins/local-storage)
